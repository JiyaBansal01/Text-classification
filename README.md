# Text Classification Project using Machine Learning

This project focuses on building a **text classification system** using **Natural Language Processing (NLP)** and **Machine Learning** techniques.  
The goal is to classify text data into predefined categories and evaluate the model’s performance using standard metrics.

---

## 📌 Features
- Text preprocessing (cleaning, tokenization, vectorization)
- Machine learning model training for text classification
- Model evaluation using accuracy and confusion matrix
- Visualization of results using heatmaps
- Clean and well-structured Jupyter Notebook implementation

---

## 🛠️ Technologies & Libraries Used
- **Python** 
- **NumPy** – numerical operations
- **Pandas** – data handling and analysis
- **Scikit-learn** – model building and evaluation
- **Matplotlib** – data visualization
- **Seaborn** – confusion matrix heatmap visualization
- **Jupyter Notebook**

---

## 📂 Project Structure
- text_classification.ipynb   # Main notebook with full implementation
- synthetic_text_data.csv    # Dataset used for training and testing
- README.md                  # Project documentation



---

## ⚙️ Workflow
1. Load and explore the dataset
2. Preprocess text data (cleaning and feature extraction)
3. Train a machine learning classification model
4. Evaluate the model using accuracy and confusion matrix
5. Visualize results using heatmaps

---

## 📊 Model Evaluation
- Accuracy score
- Confusion Matrix visualization using Seaborn heatmap
- Clear interpretation of predicted vs actual labels
